# DomKit
CSS Components based strictly typed UI framework for Haxe.

Documentation is available as part of the Heaps integration here:
https://heaps.io/documentation/domkit.html

## API documentation

The API reference is generated from the doc comments of the sources by `tools/docgen/build-api.sh`:

  - [docs/api/md](docs/api/md/README.md) : Markdown reference, one page per type
  - [docs/llms.txt](docs/llms.txt) : index of the API for AI assistants ([llmstxt.org](https://llmstxt.org) format)
  - docs/api/html : HTML site generated by [dox](https://github.com/HaxeFoundation/dox)
  - [docs/deps/DEPENDENCIES.md](docs/deps/DEPENDENCIES.md) : dependencies between the source files
