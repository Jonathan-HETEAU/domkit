DomKit API

domkit

..
Argument

A node argument (<node(arg1, arg2)>), passed to the component constructor.

AttributeValue

The value of an attribute or argument.

BezierCurve

A cubic bezier easing curve, like CSS cubic-bezier(c1x, c1y, c2x, c2y).

BytesCell

An entry of a BytesMap.

BytesMap

A map with bytes keys, used by the style cache on HashLink.

Checker

Type checks the markup and the CSS of components at runtime (for the interpreted components of Interp, or in editors such as Hide), from the types of the Heaps components (h2d.domkit.InitComponents.build() classes).

CodeExpr

Haxe code in the markup: an expression in macros, the source code otherwise.

Component

A component: the name used in the markup and in CSS (button, flow...), how to create its objects of type T, and how it handles the CSS properties. Components are created by the macros (domkit.Object classes) and registered by name.

ComponentDecl

Declares the component of another class T: a class implementing ComponentDecl<T> (with domkit.Object) defines the properties of T, for classes that can't be modified.

CssClass

A CSS selector part: component, class names, id and pseudo classes, with its parent selector.

CssData

The rules of a CssStyle, sorted by priority, and the cache of the rules matching a set of components.

CssOp

An arithmetic operator in a CSS value.

CssParser

Parses CSS style sheets and values, with the DomKit extensions: nested rules (&, >), variables (@name : value;), mixins (.name(args) { } used as .name(values);), arithmetic, and // comments.

CssRelation

The relation between a selector and its parent selector.

CssRule

A property set by a CSS rule, with its position in the source.

CssSheet

A parsed style sheet.

CssSheetElement

A CSS rule: its selectors, properties, transitions and nested rules.

CssStyle

A style: CSS rules applied to objects with Properties.applyStyle, and the running transitions, updated with updateTime.

CssTransition

A running transition of a property of an object.

CssValue

A parsed CSS value.

Curve

An easing curve: linear.

DMLChecker

Parses and type checks the markup of a component (DML), and checks CSS rules against the components.

Error

An error while parsing markup or CSS, with its position in the source.

FastBytes

Bytes used for the component bit sets of the style cache: hl.Bytes on HashLink, haxe.io.Bytes elsewhere.

HSL

A color in the HSL color space, used by the darken, lighten, saturate and desaturate color functions.

Identifier

A string (class name or id) converted to a unique integer, for fast comparisons.

Interp

Runs the markup of components with hscript instead of compiled code, to reload it while the program runs (hot reload). Enable it with domkit.Macros.allowInterp() (after hscript.LiveClass.enable()), and compile with -lib hscript -D hscriptPos.

InvalidProperty

Thrown by a property parser when the CSS value is invalid.

MToken

The states of the markup parser.

Macros

The macros of DomKit: build the domkit.Object classes (buildObject), and the configuration functions to call from an initialization macro (--macro).

Markup

A node of the markup tree.

MarkupKind

The kind of a markup node.

MarkupParser

Parses the XML-like markup of the components (static var SRC = <comp>...</comp>).

MetaComponent

The component of a domkit.Object class at compile time: reads its @:p properties and constructor, and generates its runtime Component.

MetaError

An error of the component macros.

Model

The base type of the objects of the UI, T being the base class of the components: implement it on your base class (with Heaps, h2d.Object is used).

Object

A class whose instances are built by DomKit: its @:p fields become CSS properties of its component, and its static var SRC = <comp>...</comp> markup is compiled into an initComponent() method creating the children.

ParserMode

How the value of a @:p property is parsed.

PropParser

How a property value is parsed, for the type checking of CSS values.

Properties

The DomKit state of an object (its dom field): component, id, classes, pseudo class states (hover, active...) and the CSS values set on it. Changing them marks the object to be styled again by the next applyStyle.

Property

A CSS property name, registered once with a unique id (see get).

PropertyHandler

How a component handles a CSS property: parses its value, applies it to the objects of type O, and interpolates it for the transitions.

PseudoClass

The pseudo classes of a CSS selector, as bit flags.

Rule

A CSS rule for one selector, with its priority.

RuleStyle

A property set by a Rule.

RuleTransition

A transition set by a Rule.

ScriptInterp

The hscript interpreter running the code of an interpreted component.

SetAttributeResult

The result of Properties.setAttribute.

Token

A token of the CSS lexer.

Transition

A transition of a property, declared with the transition CSS property.

TypedComponent

A component, with the types of its class, properties and constructor arguments.

TypedProperty

A property of a component, with its type.

ValueParser

Converts CSS values to property values: the parseXxx methods are used by the @:p(xxx) fields (@:p(color) uses parseColor). Extend it to add parsers, and set it with @:parser or domkit.Macros.setDefaultParser. The methods throw Property.InvalidProperty for invalid values.
